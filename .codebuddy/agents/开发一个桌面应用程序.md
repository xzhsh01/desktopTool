用 Vue3 + Vite + Electron开发一个桌面应用程序。
 功能：
    1、可用连接数据库，查询数据；
    2、可上传文件到服务器；
    3、可下载文件到本地；
    4、可进行文件管理；
    5、连接 Linux 服务器执行Shell 命令，需要包含xShell的功能;
    6、连接redis；
    7、远程连接windows；
    8、要有界面；
    9、要有菜单栏；
    10、要有托盘图标；
    11、要有状态栏；
    12、要有右键菜单；
    13、要有设置窗口；
    14、要有帮助窗口；
    15、要有关于窗口；
    16、要有日志窗口；
    17、要有退出功能；
    18、要有连接管理功能，可以添加、删除、修改连接；
    19、要有关于窗口；
    20、要有版本更新功能；
    21、要有自动更新功能；
    22、要有开机启动功能；
